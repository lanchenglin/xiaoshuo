# v0.1.0 范围与未完成项

## 已实现

- 中文网页：登录、新书、任务、正文/版本、资料、规划、调用与预算。
- 多组兼容模型配置、角色分配、密钥加密、手动连接测试。
- TXT/Markdown（UTF-8/GB18030）导入、去重、容量限制。
- 通用公开网页采集、安全DNS与重定向验证、robots检查、同站链接选择、页数上限。
- 显式采样区间、证据原文验证、分段研究与分层方法归并。
- 三方案→三开篇试写→自动评分选优→独立人物/规则/连续卷纲。
- 自动逐章细纲、正文、审稿、有限修订、长度/重复/长相同表达检查。
- 内置Humanizer-zh固定版本＋小说专用约束；润色前后保真、再次审稿、失败回退。
- 稿件版本、持久化检查点、上下文选取记录、角色/伏笔/时间状态。
- 原子保存验收章和记忆，阶段/完结摘要级复盘。
- 任务队列、暂停/恢复/取消、单实例文件锁。
- token预留、实际/保守记账区分、认证错误脱敏、有限网络与结构修复。
- TXT与项目ZIP导出，Docker和原生运行、自动化测试与CI定义。

## 明确未实现

- 小说站逐站适配、JavaScript浏览器采集、登录态、Cookie、付费/验证码处理、完整章节目录核对。
- 外部搜索引擎API。当前“自动找资料”只是在给定网址及其同站已见链接中选择，不是无限全网搜索。
- 跨网站热度统一排名、真实性可靠的浏览量采集与排序。
- Oh Story完整运行时adapter、Biz源码/运行时合并。
- 厂商原生Messages/Responses接口、网页账号模型通道。
- 独立对已有任意整本书启动“全书重润色”任务（当前是生产过程内每章润色）。
- 手工修改已验收章节后自动重算后文、人物关系图编辑、向量检索、多人协作。
- 自动修改已验收历史章节来修补最终全书审查问题；当前保留问题报告，不静默重写历史。
- EPUB/DOCX/PDF导出、项目ZIP一键导入恢复（数据库完整备份可恢复）。
- 自动投稿、平台发布、商业计费与多租户。这些不在本次范围。

## 尚未实际验证

- 你的模型Key、网关地址、真实中文长篇写作质量及成本。
- 真实小说站抓取覆盖率、真实公网DNS/TLS抓取环境、大规模章节缺失检测。
- 30万字/1000章持续运行与崩溃压力测试。
- Windows 3.11.9真机、Docker镜像构建、实际公网反向代理部署。
- 单用户应用不等于经过第三方审计的生产级公网服务。

这些项不能被演示数据、模拟HTTP测试、模型自评分或CI配置文件替代。最终交付说明需区分本地已跑测试与尚未完成的实机验收。
