# v0.2.0 范围与验收状态

## 已实现的新增代码

- 搜索、整本下载与原有原创流程接通；旧项目保留原网页采样模式。
- SearXNG JSON 搜索适配、搜索缓存、实际链接选择、来源证据记录。搜索排名不等于热度，当前热度未经验证。
- 公开 HTML 目录和目录分页读取；有限的章内分页；不把下一章并到本章。
- 逐章持久化、断点续传、已保存正文哈希校验、完全重复正文检查、缺章与目录问题报告。
- 独立的每书/项目下载字符上限；达到上限不截断章节、不把采样冒充整本。
- 默认完整性门槛，失败尝试下一候选；参考数量不足不启动创作。明确允许时才使用部分资料。
- 目录快照齐全与作者完结状态分别标记；下载全文与AI全文分析分别标记。
- 下载后可全文分段分析，或使用旧采样研究；拆书之后沿用原有原创、审稿与润色链路。
- 仅搜索下载模式无需模型，完成后可以配置模型并一键继续写作。
- 参考TXT、完整性JSON导出，目录/缺章查看，采集要求修改与重试。
- Lightnovel Crawler 独立进程桥接代码与固定上游依赖清单；仅在管理员配置 Python 路径和允许域名时启用。
- 可选 SearXNG 配置生成脚本与本机 Docker Compose 示例。
- 完整方案/部署/API/数据说明：`docs/SEARCH_DOWNLOAD_PLAN.md`。

## 本次已经实际跑过

- Python 3.14.4、Linux 环境中全部84项自动化测试通过（原有50项 + 新增34项），均为离线自编数据/模拟HTTP，不消耗真实模型token。
- Python 源码编译检查通过。
- 两个网页 JavaScript 文件使用 Playwright 随附 Node v24.21.0 完成语法检查。
- Humanizer-zh 固定版本文件校验通过。
- git diff 空白/冲突标记检查通过。

## 不能宣称已验收的项目

- 本次固定版 Lightnovel Crawler 已成功解析到上游提交，但完整依赖安装在执行时限内未完成；桥接的离线协议测试不等于实站端到端运行成功。
- 实际 SearXNG 服务、Docker启动及上游搜索引擎出网尚未验收。
- 没有针对用户实际小说网址下载整本；真实站点覆盖率、最新页面变化和完整目录可信度待实测。
- 新网页的完整浏览器交互尚未验收：测试浏览器下载中断，不能套用旧版截图/旧版浏览器结果作为本版证明。
- Windows 3.11.9 真机、Docker环境、数百万字下载/长篇模型成本与质量未实际验证。
- 外部下载器是依赖隔离的子进程，不是安全沙箱；不拥有内置 SafeFetcher 的逐请求 DNS 固定与 robots 保证。公网使用需额外隔离与网络出口约束。
