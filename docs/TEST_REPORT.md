# 初版测试记录

日期：2026-10-15。测试基线：v0.1.0。此记录区分真实执行、模拟验证和未验收项。

## 实际运行结果

- Python 3.13.5 环境：`python -m pytest`，**50 passed**。
- `python -m compileall -q app`：通过。
- Node 22：`node --check app/static/app.js`：通过。
- 离线两章端到端生产：研究→三方案/试写/选优→建书→两章写作→审稿→润色→保真→记忆→完结检查，通过。
- 真正经过httpx接口封装的完整模拟HTTP流水线：通过。使用MockTransport响应，**不是调用真实模型供应商**。
- Chromium离线页面渲染与实际JS交互，通过FastAPI TestClient桥接API：登录、建书、自动两章、阅读版本、保存/重新脱敏显示Key、390px手机布局通过，未见JS异常或页面横向溢出。
- 测试中发现并修复了侧栏作品名/进度不随主面板刷新而更新的问题。

## 测试覆盖

- 同一本书重复启动拦截、人工暂停、缺少参考正文停止。
- 成功步骤/模型响应缓存复用、重启对请求中状态的保守记账。
- 请求前预算保护、保守上下文限额、无静默截断。
- 模型401脱敏、超时最多重试一次、无usage的保守统计。
- 非法JSON只修复一次、截断输出不验收、模型超大响应拒绝。
- 三方向语义ID校验、卷纲覆盖校验、路径片段约束。
- 章节质量不过关有限修订后阻塞、不伪造成功。
- 润色保真失败保留已过关原稿、拒绝稿版本可查。
- 来源URL、内网/回环/IPv6映射/多播、混合DNS结果、私网重定向拦截。
- 固定解析IP并保留Host/TLS SNI的请求构造、下载大小限制。
- robots拒绝与404、静态HTML提取、采样范围记录。
- 模板表达只做线索，不自动作AI身份判定。
- API登录、写请求来源检查、密钥加密与不回传、Key留空保留。
- UTF-8/GB18030上传、重复资料、任务启动后封存参考资料。
- TXT章节顺序、项目导出不包含Key、文件路径约束。
- 单实例worker锁。

## 测试方法限制

- 环境管理策略阻止Chromium直接导航到本地HTTP网址（ERR_BLOCKED_BY_ADMINISTRATOR）。未绕过该策略；改用**离线页面＋TestClient桥接**做渲染和交互验证。因此这不等于真实网络下的浏览器Cookie/CSP/代理端到端验收。
- 本地模拟小说用自编小说润色约束；Humanizer上游规则固定版本随仓库内置，通过文件哈希核对。没有把模型模拟响应当作该规则的真实文学效果实测。
- 没有用户真实API Key，未进行真实模型费用、长篇质量、去模板表达成效评估。
- 公网页面读取使用模拟HTTP与DNS做回归，未证明特定小说网站已适配。
- 原生测试环境为Linux/Python3.13。CI定义覆盖3.11/3.12/3.13，但“存在CI定义”不代表所有GitHub Actions运行已经成功；须查看实际Actions结果。
- Docker、Windows真机、公网TLS、长篇压力和崩溃故障注入仍见STATUS中的未验收项。
